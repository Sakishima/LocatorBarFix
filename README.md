# LocatorBarFix

Небольшой Paper-плагин для обхода клиентского сбоя Locator Bar на Minecraft 26.2.

## Назначение

Плагин перехватывает исходящие waypoint-пакеты и предотвращает отправку операции `UPDATE`, если соответствующий waypoint ранее не был зарегистрирован операцией `TRACK` для того же получателя.

Обычная работа Locator Bar сохраняется: корректные `TRACK`, `UNTRACK` и `UPDATE` не изменяются. Сам плагин не отключает Locator Bar и не вмешивается в отображение меток.

## Совместимость

- Minecraft / Paper API: **26.2**
- Java: **25**
- Kotlin
- PacketEvents: **2.13.0** (обязательная внешняя зависимость)

Проект ориентирован на Paper 26.2 и совместимые серверные ядра, включая форки Paper. PacketEvents должен быть установлен отдельно и загружаться раньше этого плагина.

## Сборка

Требуется JDK 25 и Gradle 9.2 или новее.

```shell
gradle clean build
```

Готовый плагин появится в `build/libs/`. Используйте JAR без суффикса `-all` (Shadow JAR), содержащий Kotlin runtime. PacketEvents в JAR не включается.

## Установка

1. Установите PacketEvents версии 2.13.0 или совместимую сборку, поддерживающую Minecraft 26.2.
2. Поместите JAR LocatorBarFix в каталог `plugins`.
3. Полностью перезапустите сервер.
4. При необходимости включите диагностические сообщения в `plugins/LocatorBarFix/config.yml`.

## Архитектура

Исходный код разделён по назначению:

- `domain` — модели waypoint и решения фильтра.
- `application` — прикладная логика защиты.
- `infrastructure.packet` — адаптация PacketEvents и обработчик сетевых событий.
- `infrastructure.persistence` — потокобезопасное хранение состояния waypoint.
- `configuration` — загрузка настроек.
- корневой класс плагина — сборка зависимостей и управление жизненным циклом.

Состояние хранится отдельно для каждого получателя. Переходы выполняются атомарно, чтобы параллельная обработка сетевых событий не приводила к повреждению реестра.\n\nФильтр UPDATE работает на приоритете HIGHEST. Изменения состояния TRACK и UNTRACK фиксируются отдельным наблюдателем на MONITOR — только после того, как остальные обработчики приняли окончательное решение и пакет не был отменён. Поэтому отменённый сторонним плагином TRACK не создаёт ложную запись в реестре.

## Ограничения

Это серверный обходной путь для ошибки синхронизации waypoint, а не исправление клиента Minecraft. Он не может гарантировать отсутствие всех причин клиентского сбоя и не заменяет тестирование на конкретной сборке ядра и наборе плагинов.

## Диагностика

По умолчанию диагностические сообщения отключены. При включении режима отладки плагин сообщает о заблокированных обновлениях waypoint. Не публикуйте логи с персональными данными без предварительной проверки.
